# 旧データベースのSQL（参考用・適用禁止）

旧Supabaseプロジェクト（kawntunevmabyxqmhqnv、2026年に消失）で使っていたSQLです。
**新しいプロジェクトには絶対に流さないでください。** 現在のスキーマは `supabase/migrations/` にあります。

このフォルダには、次のような重大なセキュリティ問題が含まれています（2026-11-27 の自動検査）。

- 利用者が自分のポイントや権限（role）を書き換えられる（015, 035）
- 送金・紹介ボーナスの関数で他人になりすませる、金額を利用者が決められる（004, 016）
- 利用者がポイント履歴やスタンプを自分で追加できる（002, 20260213130000）
- メニューの RLS が無効、または誰でも他店のメニューを変更できる（006, 045）
- 未使用の店舗招待コードが誰でも読める（030）
- 市町村データを誰でも変更できる（007）

機能を作り直すときは、仕様の参考にだけ使い、権限まわりは新しく設計してください。
